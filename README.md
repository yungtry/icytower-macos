  # Icy Tower (macOS)

  Native macOS Metal port of Icy Tower 1.3.
</div>

## Build

Open `IcyTower.xcodeproj` in Xcode and press **⌘R**, or build via CLI:

```bash
xcodebuild -scheme IcyTower -configuration Release build
```

## Controls

| Key | Action |
| --- | --- |
| **← / →** | Move |
| **Space** | Jump |
| **Enter** | Select |
| **Esc** | Pause / Back |
